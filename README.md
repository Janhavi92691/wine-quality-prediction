# Wine Quality Prediction System

## Project Overview
This project uses Machine Learning to predict the quality of wine based on physicochemical tests.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib/Seaborn
* **Environment:** Google Colab

## The Data
* Analyzed 1,599 red wine samples to classify quality as either GOOD or BAD based on physicochemical properties.

## Models Evaluated
* Implemented and compared Logistic Regression, K-Nearest Neighbors (KNN), and Decision Tree classifiers.

## Dataset
The dataset includes features like acidity, sugar levels, and alcohol content. 

## How to Run
1. Upload the `.ipynb` file to Google Colab.
2. Upload the dataset to the Colab session.
3. Run all cells.
